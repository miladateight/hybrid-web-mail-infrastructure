# Web Platform

The web platform portion covered design, implementation and deployment of a corporate website presentation layer.

## Work Performed

- Implemented the website layer.
- Deployed it to a Linux hosting environment.
- Managed HTTPS and TLS behavior.
- Coordinated reverse proxy behavior.
- Validated service health after changes.

## Public Repository Boundary

This repository does not include the production website, original text, real screenshots, real assets or source code copied from the live site.

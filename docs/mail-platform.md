# Mail Platform

The mail platform included SMTP, IMAP and webmail administration.

## Components

- Exim for SMTP transport and submission concepts.
- Dovecot for IMAP mailbox access concepts.
- Roundcube for browser-based webmail concepts.
- SPF, DKIM, DMARC, MX and PTR as DNS authentication and deliverability concepts.

## Operational Focus

Milad configured and maintained access paths, TLS behavior, outbound mail routing concepts, relay integration and troubleshooting workflows.

## Sanitization

No mailbox content, mail headers, real domains, DKIM material, DNS record values, SMTP credentials or relay settings are present.

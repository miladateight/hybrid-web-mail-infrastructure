# بنية هجينة للويب والبريد المؤسسي

## إشعار دراسة الحالة المجهولة

هذا المستودع دراسة حالة مجهولة للملف المهني. ليس هو موقع الإنتاج، وليس نسخة احتياطية للبنية التحتية، وليس مستودع نشر. تم حذف هوية الشركة والنطاقات وأسماء المضيفين وعناوين الشبكة وبيانات الاعتماد وصادرات التكوين واللقطات ومصدر الإنتاج عمدا.

## نظرة عامة

يعرض هذا المشروع موقع GitHub Pages متعدد اللغات حول مشروع بنية ويب وبريد وشبكة هجينة أنجزه Milad. تشرح دراسة الحالة القرارات الهندسية والمسؤوليات والممارسات التشغيلية وراء منصة موحدة لتسليم الموقع، واستضافة Linux، والبريد المؤسسي، والوصول الخارجي الآمن، والاتصال الداخلي الموجه.

## تحدي المشروع

احتاجت المؤسسة إلى منصة قابلة للصيانة لموقع عام، واستضافة مركزية للويب والبريد، ووصول داخلي وخارجي موثوق، وخدمات مؤمنة عبر TLS، ومصادقة بريد مبنية على DNS، ومسارات بريد صادر مضبوطة، وجاهزية نسخ احتياطي، ووثائق عملية لاستكشاف الأعطال.

## دوري

صمم Milad وطبق طبقة الموقع، ونشر بيئة الاستضافة، وأدار خدمات Linux، وكون HestiaCP وNginx وExim وDovecot وRoundcube، ودمج سلوك Reverse Proxy، ونسق مصادقة DNS، وكون مفاهيم الاتصال الآمن، ووثق إجراءات الاسترداد.

## المسؤوليات

- تصميم الموقع وتنفيذه.
- نشر الموقع وإدارة الاستضافة.
- إدارة خادم Linux والتحقق من الخدمات.
- إدارة HestiaCP وNginx وTLS.
- إدارة Exim SMTP وDovecot IMAP وRoundcube webmail.
- تخطيط الوصول الداخلي والخارجي.
- دمج HAProxy وWireGuard وMikroTik RouterOS.
- تنسيق Firewall وNAT وPolicy-Based Routing.
- مفاهيم توجيه SMTP الصادر حسب النطاق.
- تخطيط النسخ الاحتياطي والمراقبة واستكشاف الأعطال وتوثيق الاسترداد.

## المعمارية على مستوى عال

تشمل المعمارية المعممة مستخدمين خارجيين، مستخدمين داخليين، Public DNS، European VPS، HAProxy، سلوك SMTP Relay، نفق WireGuard آمن، MikroTik Edge Router، Reverse Proxy Server، HestiaCP Web and Mail Server، Nginx، Exim، Dovecot، Roundcube، تخزين النسخ الاحتياطي، المراقبة والسجلات.

لا يتم تضمين أي عناوين IP أو نطاقات أو أسماء مضيفين أو أسماء واجهات أو أسماء مزودين أو قيم توجيه دقيقة.

## عمل الموقع والاستضافة

يغطي جزء الويب طبقة عرض الموقع، واستضافة Linux، وإدارة HestiaCP، واستضافة Nginx، وتكامل Reverse Proxy، وإدارة HTTPS وTLS، وتسليم الأصول الثابتة، وفحوصات الصحة بعد التغيير. لا يتضمن المستودع مصدر موقع الإنتاج أو محتوى الشركة الأصلي.

## بنية البريد

يغطي جزء البريد Exim SMTP وDovecot IMAP وRoundcube webmail والوصول المؤمّن عبر TLS والوصول الداخلي والخارجي إلى صناديق البريد ومصادقة DNS ومفاهيم التسليم الصادر المضبوط. قام Milad بتكوين هذه التقنيات وإدارتها واستكشاف أعطالها؛ ولا تدعي دراسة الحالة أنه طورها.

## الوصول الداخلي والخارجي

وصل المستخدمون الداخليون إلى الخدمات عبر مسار شبكة المؤسسة. وصل المستخدمون الخارجيون إلى نقاط دخول عامة محددة عبر European VPS معمم وطبقة Proxy أو Relay. الوصف مقصود أن يبقى مفهوميا.

## الاتصال الهجين

استخدم المشروع مفهوم نفق آمن بين مواقع البنية التحتية. تولى MikroTik RouterOS توجيه الحافة وحدود Firewall وNAT وPolicy-Based Routing.

## مفهوم توجيه SMTP حسب النطاق

تم تخطيط البريد الصادر حول مسارات مباشرة ومسارات Relay منفصلة. يشرح الملف المهني المفهوم من دون نشر نطاقات حقيقية أو selectors أو قيم DNS أو بيانات اعتماد أو تكوين Relay.

## DNS ومصادقة البريد

تمت مراعاة SPF وDKIM وDMARC وMX وPTR كمفاهيم لهوية البريد وقابلية التسليم والثقة. لا توجد قيم سجلات حقيقية في هذا المستودع.

## النهج الأمني

ركز العمل الأمني على TLS وتقليل التعرض وحدود Firewall ونظافة بيانات الاعتماد وفصل التكوين ومراجعة الخصوصية ومعالجة النسخ الاحتياطية والتوثيق العام الآمن.

## النسخ الاحتياطي والاسترداد

تشرح دراسة الحالة تخطيط النسخ الاحتياطي والتحقق من الاسترداد وعملية استرداد الحوادث بطريقة منقحة. يتم تجنب السجلات الحقيقية ومسارات نظام الملفات وتاريخ الأوامر وتفاصيل الحوادث غير المثبتة.

## استكشاف الأعطال

يعرض استكشاف الأعطال كعملية هندسية منظمة: ملاحظة الأعراض، عزل الطبقات، التحقق من صحة الخدمة، تحديد فئة السبب الجذري، استعادة المكونات المطلوبة، التحقق من السلوك، وتوثيق الإجراءات الوقائية.

## التقنيات

الويب والاستضافة: HTML، CSS، JavaScript، Linux، Ubuntu Server، HestiaCP، Nginx، TLS.

البريد: Exim، Dovecot، Roundcube، SMTP، IMAP، SPF، DKIM، DMARC، MX، PTR.

الشبكة: MikroTik RouterOS، WireGuard، HAProxy، NAT، Firewall، Policy-Based Routing، DNS، TCP/IP.

العمليات: Bash، Logging، Monitoring، Backup، Incident Recovery، Troubleshooting وTechnical Documentation.

## المهارات المعروضة

ملكية بنية تحتية شاملة، استكشاف أعطال عبر مجالات متعددة، إدارة Linux، إدارة بنية البريد، هندسة الشبكات، الوصول الآمن عن بعد، تكوين Reverse Proxy، توجيه SMTP، إدارة DNS، إدارة TLS، تخطيط النسخ الاحتياطي، استرداد الحوادث والتوثيق الفني.
